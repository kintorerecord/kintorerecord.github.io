# kintorerecord.github.io

Android アプリ「筋トレレコード」の紹介ページです。GitHub Pages で `https://kintorerecord.github.io/` に公開しています。

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップページ（Play の掲載情報の「ウェブサイト」に登録する） |
| `app-ads.txt` | AdMob の app-ads.txt。`pub-` の後ろは AdMob のパブリッシャー ID |
| `privacy-policy.md` | プライバシーポリシー（アプリ内と Play Console からリンク） |
| `terms.md` | 利用規約（アプリ内からリンク） |

`privacy-policy.md` と `terms.md` の元の文書は `toshi-atresta-lab/training` リポジトリの `docs/` にあります。元の文書を直したら、こちらにもコピーしてください。
